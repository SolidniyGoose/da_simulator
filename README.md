# Симулятор по дискретному анализу

Пошаговые симуляции алгоритмов и структур данных к экзамену, теория с доказательствами и тренажёр.

Готовы все билеты 1–22 и дополнение 8+ (неявные декартовы деревья):

- I — линейные сортировки;
- II — деревья поиска, AVL, красно-чёрные, декартовы, B-деревья, trie, PATRICIA;
- III — поиск образца;
- IV — суффиксные деревья и массивы.

## Вариант 1. Открыть в браузере (GitHub Pages)

Ссылка: `https://<логин>.github.io/<репозиторий>/`

- Всегда открывается последняя версия, ничего скачивать не нужно.
- Работает и без интернета: открывается версия, загруженная в прошлый раз.

## Вариант 2. Локальная копия

1. Скачай проект одним из способов:
   - кнопкой **Code → Download ZIP** на GitHub (Git не нужен), затем распакуй архив;
   - командой `git clone https://github.com/<логин>/<репозиторий>.git`.
2. Запусти:
   - на Windows — **`start.bat`**;
   - на Mac или Linux — `start.sh` (один раз выполни `chmod +x start.sh`).

При каждом запуске скрипт проверяет обновления на GitHub и только потом открывает `index.html`:

- если папка — git-клон и Git установлен, выполняет `git pull`;
- иначе сравнивает версию с GitHub и, если там новее, скачивает архив и распаковывает его поверх папки.

Без интернета запустится текущая версия.

Если открыть `index.html` напрямую, а на GitHub есть версия новее, сверху появится плашка с напоминанием запустить `start.bat`.

> Windows может предупредить, что `start.bat` скачан из интернета. Это нормально: нажми «Подробнее → Выполнить в любом случае».

## Для автора: как выпустить обновление

1. **Один раз:** впиши свой репозиторий в `js/version.js`: `repo: 'логин/репозиторий'`.
2. После изменений запусти из папки проекта:

   ```
   powershell -ExecutionPolicy Bypass -File tools\release.ps1 "что изменилось"
   ```

   Скрипт повысит версию в `js/version.js` (формат `год.месяц.день.номер`), закоммитит изменения и выполнит `git push`.

Номер версии — то, по чему локальные копии понимают, что пора обновиться. Поэтому не пушь изменения без `release.ps1`, иначе версия останется прежней.

## Структура

| Путь | Что там |
| --- | --- |
| `index.html`, `css/` | Страница и стили |
| `js/core.js`, `js/main.js` | Оболочка: оглавление, плеер шагов, тренажёр |
| `js/algo.js`, `js/stree.js`, `js/bst.js` | Общие алгоритмы и отрисовка |
| `js/topics/tNN-*.js` | По файлу на билет |
| `js/version.js` | Версия и адрес репозитория |
| `js/update.js` | Проверка обновлений на странице |
| `sw.js` | Офлайн-режим на GitHub Pages |
| `start.bat`, `start.sh`, `tools/update.ps1` | Запуск локальной копии с обновлением |
| `tools/release.ps1` | Выпуск новой версии |
